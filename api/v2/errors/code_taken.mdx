---

**HTTP 409**

Another resource of the same kind already uses this code: a catalog resource's `code` (a plan, a product, a metric…, at `/code`), a subscription's `external_id` (at `/external_id`), a custom property definition's `key` (at `/key`). Unarchiving a coupon or a feature while a live one holds its code answers it too.

**What to do:** Choose another code, or read the resource that holds it.
