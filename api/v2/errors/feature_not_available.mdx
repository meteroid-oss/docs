**HTTP 403**

The organization's plan or edition does not include this feature, or it is not turned on for the organization: usage costs, usage breakdowns, budgets, custom property definitions, event corrections, licensing, credit pricing, automatic top-ups, a Connect platform. The operations the open-source edition does not serve say so in their description (`Enterprise edition.`).

**What to do:** Check your plan or edition, or turn the feature on for the organization; `detail` names it.
